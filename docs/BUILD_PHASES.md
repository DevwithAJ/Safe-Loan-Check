# Build Phases

## Phase 1 — Problem evidence
- Final problem statement
- Anonymous Google Form
- 100+ responses
- Survey analysis

## Phase 2 — Directory verification
- Download/save dated DLA source
- Normalize app + developer names
- Exact + fuzzy matching
- Show Listed / Not listed / Unclear

## Phase 3 — App dataset
- Collect 150–300 public app listings
- Keep source URLs/dates
- Create traceable labels
- Exclude uncertain apps

## Phase 4 — EDA + feature engineering
- Missing values
- Class balance
- Permission frequencies
- Rating/install distributions
- Review complaint features
- Similarity features

## Phase 5 — Baseline + ML
- Baseline: contact permission rule
- Logistic Regression
- Random Forest
- XGBoost (optional)
- Recall, precision, F1, PR-AUC, confusion matrix
- Hold-out evaluation

## Phase 6 — Cost calculator
- Net amount received
- Total repayable
- Monthly IRR
- Annualised APR
- EMI/income ratio
- 5 hand-worked tests

## Phase 7 — Decision Layer + UI
- Green / Amber / Red
- Top 3 reasons
- Hindi + English
- Disclaimer

## Phase 8 — Pilot
- 30 volunteers
- Pre-test / post-test
- Usability + confidence
- Honest reporting

## Phase 9 — Error analysis
- Review false negatives
- Review false positives
- Tune threshold only using validation data

## Phase 10 — Final report/demo
- Revised abstract
- Metrics tables
- Confusion matrix
- Survey charts
- Pilot results
- Demo video + PPT
