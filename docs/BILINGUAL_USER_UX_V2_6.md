# Safe Loan Check v2.6 — Bilingual User-Friendly UX

## Goal
Make the result understandable to a first-time borrower before showing reviewer-oriented technical evidence.

## First visit language flow
1. Website opens with a blocking language selection card.
2. User chooses English or हिंदी.
3. Preference is stored in the session and a same-site language cookie.
4. The header keeps an EN / हिंदी switch for later changes.

## Result hierarchy
The result page now presents information in this order:
1. Overall Green / Amber / Red result.
2. Plain-language meaning.
3. Four simple status cards: identity, AI signal, public listing, and loan cost.
4. “Why did I get this result?” explanation.
5. Before-borrowing actions.
6. Green / Amber / Red color guide.
7. Collapsible technical details for reviewers.

## Amber wording
Amber means caution, not rejection. A typical listed-app Amber result explains that the RBI-directory identity matched but public-listing permissions/transparency or cost signals still need review.

## Important boundary
Green does not mean RBI approval, a cheap loan, or a recommendation. Red does not declare an app illegal. The tool remains an educational awareness system.
