# Pilot Study — Ready to Run

This folder contains the ready-to-use 30-participant pilot materials for Safe Loan Check.

## Files
- `Safe_Loan_Check_Pilot_Study_Pack.docx` — participant consent, pre-test, intervention instructions, post-test, cost questions and usability feedback.
- `Safe_Loan_Check_Pilot_Scoring_Tracker.xlsx` — anonymous P01–P30 tracker with answer keys, automatic scoring, pre/post deltas and a summary dashboard.
- `pre_test_items.csv` / `post_test_items.csv` — compact item lists for form-building or data entry.

## Procedure
1. Recruit 30 student volunteers and obtain informed consent.
2. Use Participant IDs only; do not collect names, phone numbers, bank details or real personal loan amounts.
3. Run the pre-test.
4. Allow 15–20 minutes with Safe Loan Check.
5. Run the different post-test and collect confidence/usability ratings.
6. Enter genuine participant responses in the Excel tracker.
7. Report improvement, no change, or decline honestly.

## Important wording
The pilot uses project labels for evaluation. It does not determine whether an app is illegal, RBI-approved, or suitable for an individual borrower.
